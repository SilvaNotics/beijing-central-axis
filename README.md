# 京华一线 · 北京中轴线数字长卷

以北京中轴线为线索的中文交互式城市图志。项目把遗产点介绍、建筑模型、道路与水系组织在同一张地图中，以午后至黄昏的暖色光线呈现从钟鼓楼到永定门的空间序列。

在线访问：[京华一线 · GitHub Pages](https://silvanotics.github.io/beijing-central-axis/)。主分支更新后由 GitHub Actions 自动构建发布，配置与操作见 [部署说明](docs/development.md#github-pages)。

## 项目内容

- **城市总览**：Three.js 三维图景与可切换的二维地图，支持平移、缩放、方向调整、分区聚焦和遗产点选取。
- **遗产导览**：围绕 15 项遗产构成要素，展示名称、时代、简介与参考资料。
- **三个章节入口**：北段、中段与南段均已接入独立章节；章节通过 iframe 接入，可分别采用 React、Vue 或原生网页。
- **样例页面**：提供独立的展示路由，便于演示与后续扩展。

| 分区 | 内容范围 |
| --- | --- |
| 北段 | 钟鼓楼、万宁桥、景山 |
| 中段 | 故宫、社稷坛、太庙、端门、外金水桥 |
| 南段 | 天安门城楼、天安门广场及建筑群、正阳门、天坛、先农坛、中轴线南段道路遗存、永定门 |

## 技术与资料

主应用采用 React、TypeScript 和 Vite，三维场景采用 Three.js。字体和运行资源使用本地文件或系统资源；生产构建可通过静态 HTTP 服务运行，无需在线地图瓦片、CDN 脚本或运行时 AI 服务。

文化介绍、地图轮廓和建筑观察分别记录来源，研究材料保存在 `docs/research/`。模型用于空间理解和导览，包含简化、推估与显示调整，不作为测绘成果、法定遗产边界或精确历史复原。

北段已接入正式章节「纸雕立体书地图」，中段已接入互动画卷「京华入画」，南段已接入独立互动章节「京华入墨 · 中轴拾光」。人物和对话采用创作叙事，资料依据与素材授权待补项见各章节交付说明。

音频资源均随包分发、无运行时外部请求：背景音乐《Ripples》（Kevin MacLeod，CC BY 4.0）、界面音效（CC0 / 公有领域）、游览播报与讲解（本项目用 Microsoft Edge TTS 预生成，仅用于课程演示，重生成脚本为 `scripts/gen-tour-voice.py`，讲解稿加 `--brief`）。

项目运行、工程结构、章节契约和研究资料见 [文档目录](docs/README.md)。
