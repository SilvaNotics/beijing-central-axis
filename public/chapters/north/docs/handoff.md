## 已知限制

1. **开场动画清晰度**：源为 720p 生成视频，运动段无法补细节；首帧与 0–0.85s 已用高分辨率静帧顶替，全屏 1080p 观感可接受，2K 以上会显软。
2. **窄屏未适配**（见上表）：需要在竖屏下改版对话版式，尚未实现，交付时按桌面与横屏使用。
3. **进度不落盘**：刷新即重置，仅内存记录。
4. **历史事实的登记**：本页信息在介绍卡内标注了出处，但未写入主项目 `docs/research/source-register.json`（来源体系与本次引用的出版/机构条目不一致）。若需要，可按主项目 ID 体系补登记。
5. **未提供章节内返回链接**：按 `docs/integration.md` 的分工，返回总览由父应用提供；为避免与父层按钮重复，本页未内置 `data-return` 链接。如需，可加 `<a href="../../#/" data-return>` 并在同源嵌入时 `postMessage({type:'axis:return'})`。
