# 北段 · 纸雕立体书地图

北京中轴线北段（钟鼓楼—万宁桥—景山）的独立章节页。整页是“翻开一本立体书”的形式：合着的布面书打开，纸雕城市从书页上立起，随后进入可交互地图。

## 内容

- 开场：5 秒立体书展开动画，点击画面开始（浏览器要求用户手势后才能出声），可跳过。
- 地图：一张 16:9 纸雕底图，四个地名签（钟楼、鼓楼、万宁桥、景山公园）。
- 介绍卡：四处地标各一张，列年代、规模，景山另列五亭；每张末尾标“出处”。
- 人物：三名 NPC（钟鼓楼的铜匠、万宁桥的船工、景山的役夫），各有 13–14 句台词与考据小注。
- 配乐与音效：开场结束后的界面循环背景音乐；翻页、展开纸的音效。

## 事实出处

页面内每张介绍卡的末行即出处，分别为：

- 钟楼：北京市文物局《龙尾之曜——浅记北京鼓楼》
- 鼓楼：北京市文物局；北京市文旅局
- 万宁桥：北京市文物局《万宁桥》；北京市文旅局
- 景山：首都之窗·景山公园；北京市公园管理中心

人物台词中的考据小注按“所记何物—见于何书”的形式标注，涉及《元史》《明实录》《日下旧闻考》《析津志》等。
