# 京华入画 · 北京中轴线中段

「京华入画」是北京中轴线图集的中段独立静态章节，以画卷式导览图承载故宫、社稷坛、太庙、端门和外金水桥五处互动站点。章节通过主应用的 `central` iframe 入口接入，也可独立打开。

## 页面结构

- `index.html`：页面结构、样式和交互逻辑。
- `assets/`：导览画卷、五张建筑画卷、五张人物图及三段视频。
- `docs/`：来源边界、素材状态与交付记录。

访客点击地图人物后先看到对应建筑画卷，再次点击人物可进入影像或文字讲述；顶栏记录本次浏览进度。页面内另有可选的“微调人物位置”工具，用于在浏览器本地调整人物热点位置，不修改提交到仓库的默认值。

地图在首次点击或按键后循环播放与北段相同的本地配乐，顶栏“音乐”按钮可关闭。进入建筑画卷、视频或文字讲解后立即暂停，关闭弹层回地图时恢复；用户手动关闭音乐后不会自动重开。

地图是创作性导览画面，人物位置是交互热点，不是实测坐标、遗产边界或测绘成果。历史内容沿用主项目已登记来源，详细边界见[来源与素材说明](docs/sources.md)。
