# 来源与素材说明

## 历史内容

本页没有新增历史来源，也没有在本轮重新访问或核验外部来源。内容沿用主项目的稳定来源 ID；登记日期、原核验状态和限制以[研究来源目录](../../../../docs/research/source-catalogue.md)与[证据矩阵](../../../../docs/research/evidence-matrix.md)为准。

| 页面内容 | 沿用来源 ID | 当前使用边界 |
| --- | --- | --- |
| 中轴线与宫城礼序 | `GEN-AXIS`、`GEN-BEIJING`、`GEN-PLAN` | 支持宫城、坛庙与轴线关系；不用于证明页面插画比例或人物点位。 |
| 故宫 | `GEN-PALACE`、`GEN-AXIS` | 支持明清皇宫、宫城院落和遗产背景；详细年代、尺寸与仪式描述仍需逐句回对专门来源。 |
| 社稷坛、太庙 | `GEN-BEIJING`、`GEN-PLAN`、`GEN-AXIS` | 支持宫城西侧社稷坛、东侧太庙及礼制空间关系；页面未给出精确平面或现状测绘。 |
| 端门 | `DUAN-DPM`、`GEN-BEIJING` | 馆方院刊资料支持端门大楼九间、进深五间及尺制尺寸；城台高度、各檐标高和完整立面仍缺测绘依据。端门具体启闭、仪仗与“端礼门”等叙述尚未逐句回对来源。 |
| 外金水桥 | `JINSHUI-SWJ`、`JINSHUI-2019` | 支持七座桥、五座主桥对应天安门五门洞及外侧两桥通往坛庙；两来源对桥孔数存在冲突，页面不据此推断逐桥孔数。重建年代和桥群等级通行细节仍待逐句复核。 |

页面中的“介绍者”是现代导览角色，不是历史人物肖像、证言或档案引文。中央地图来自用户提供的创作画面，用于关系性浏览和热点定位；人物坐标、镜头关系和地图边界不得解释为实测数据。建筑画卷与视频是表达或纪录素材，不构成建筑形制认证。

| 素材 | 文件位置 | 当前记录 |
