# 来源与素材说明

本页没有新增历史来源，也没有在本轮重新访问或核验外部来源。事实核对沿用主项目的稳定来源 ID；其登记日期、原核验状态与限制以[研究来源目录](../../../../docs/research/source-catalogue.md)和[证据矩阵](../../../../docs/research/evidence-matrix.md)为准。

| 页面内容 | 沿用来源 ID | 使用边界 |
| --- | --- | --- |
| 天安门城楼与广场空间 | `TIAN-DPM`、`TIAN-VISIT`、`GEN-AXIS` | 主应用中两个地标合并叙事不改变其独立登记；事件顺序仍需逐句复核。 |

## 媒体素材

运行素材从用户提供的 Windows 桌面 `masterpiece` 目录整理并复制到 `assets/`。源目录没有附带可核验的作者、原始链接、许可文本或授权凭证，本项目目前无法确认其再分发权利。素材应视为**授权待核**，不能据文件可访问推定允许公开发布。需由素材提供者补充每项媒体的作者/权利人、原始出处和许可或书面授权。

| 素材 | 文件位置 | 当前记录 |
| --- | --- | --- |
| 导览地图 | `assets/map.png` | 作者、来源与许可待补。 |
| 六张人物立绘 | `assets/portraits/` | 每张的作者、生成/制作方式、来源与许可待补。 |
| 背景音乐 | `assets/music/ambient.mp3` | 作曲/表演者、录音来源与许可待补。 |
| 五段景点视频 | `assets/videos/` | 摄制者、片段来源、画面/音乐权利与许可待补。 |

没有在结构化来源登记中为这些未明素材虚构作者或许可。获得可核验信息后，再按主项目的来源维护要求补充来源登记和本表。
