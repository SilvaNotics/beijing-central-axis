# 南段互动章节

「京华入墨 · 中轴拾光」是北京中轴线图集的南段独立静态章节，以地图热点、人物讲述、配音和视频呈现六处叙事站点。页面通过主应用的 `south` iframe 入口接入，也可独立打开。

## 页面结构

- `index.html`：页面结构与无障碍标签。
- `styles.css`：章节样式和窄屏布局。
- `app.js`：六个站点的数据、交互、声音和视频逻辑。
- `assets/`：地图、立绘、配音、背景音乐和站点视频。
- `docs/`：素材来源、内容边界与交付记录。

天安门城楼与天安门广场及建筑群在章节内合并为一个叙事站点；主应用登记仍分别保留 `tiananmen` 与 `square` 两个稳定地标 ID。

人物及对白为创作叙事，不是历史人物证言或档案引文。详细事实范围及媒体授权状态见[来源与素材说明](docs/sources.md)。
