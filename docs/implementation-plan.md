# 已确认实施计划

确认日期：2026-11-13。此文档记录本轮实现边界，后续详细章节替换遵循接入契约。

## 目标与呈现

以北京中轴线的整体地理关系为核心，制作一个有空间感、可操作且可由团队继续扩展的中文图志。首页采用午后至黄昏的暖色光线，三维概览有连续轴线、代表性建筑、周边道路与水系。以具体遗产点入口连接整体空间和知识说明，避免用通用营销卡片取代地图。

场景为依据地理资料简化的导览模型。保留南北方位、主要相对位置和场所识别性；不声称提供测绘精度或某一历史年代的复原。

## 技术决定

1. 以 React + TypeScript + Vite 实现主应用，以 Three.js 实现场景；资源本地化，不引入在线地图底图、远程字体或运行时 AI。
2. 数据与表现分离：`src/data/heritage.ts` 保存遗产点、来源与分区登记，场景读取相同数据，界面不重复维护另一套入口表。
3. 使用哈希路由保持普通静态 HTTP 服务可用：`#/`、`#/chapter/{north|central|south}`、`#/site/{id}`、`#/sample`。
4. 三个章节默认通过 iframe 接入。各章节可使用独立 React、Vue 或原生网页并自由选择美术风格；主应用保留返回概览与独立打开功能。
5. 先交付三个明确标注的「分区接入示例」，验证集成边界；正式详细内容保留给各章节作者。替换只需替换静态产物或登记入口。
6. 应用预览和最终使用都经本地 HTTP 服务运行，不依赖 `file://`；支持同源本地章节离线展示。

## 内容分区

| 分区 ID | 范围 | 初始示例 |
| --- | --- | --- |
| `north` | 景山、钟鼓楼、万宁桥 | 墨绿园林与垂直导览 |
| `central` | 故宫、社稷坛、太庙、端门、外金水桥 | 朱红宫城与轴向序列 |
| `south` | 天安门城楼、天安门广场及建筑群、正阳门、天坛、先农坛、中轴南段道路遗存、永定门 | 赭金城市与南向展开 |

研究记录必须区分官方资料、坐标与为渲染做的简化。中文介绍使用可追溯的事实来源。章节示例只承诺示意范围与跳转行为，不承载未完成的详细研究内容。
