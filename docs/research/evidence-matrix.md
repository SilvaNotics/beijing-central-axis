# 逐地标证据、建模取舍与待补事项

整理日期：2026-11-13。覆盖 `src/data/heritage.ts` 中15项稳定要素。这里记录资料与设计的对应关系，**不是所有建筑均已完成精确复原的验收表**。本轮代码仍在迭代，完成情况应以最终提交和验证记录为准。

来源编号对应 [来源目录](source-catalogue.md) 与 [结构化登记](source-register.json)。使用四种证据口径：**文字事实**（来源明确说明）、**地图几何**（位置/轮廓/属性）、**照片观察**（可见形态）、**模型解释**（为导览补足或简化）。同一建筑可同时包含四种，不能因为某个高度有官方数字就把其全部细部称为实测。

- **文化依据**：`GEN-AXIS`、`GEN-BEIJING`支持两楼作为一项要素、城市报时功能及中轴北端关系。
- **建筑依据**：`TOWER-HERITAGE`区分鼓楼46.7米、三重檐、五间三进深和基座券洞，与钟楼47.9米、砖石主体、双檐歇山。`TOWER-CITY`补充官方背景；`VIS-LIBRARY`的航拍和立面图帮助观察两楼的相对体量。
- **地图几何**：分别采用建筑way `425993664`（钟楼）与 `267371087`（鼓楼）的位置和外轮廓。高德钟楼/鼓楼检索还存在其他区县同名结果，筛选过程保存在初始查询文件。
- **设计取舍**：两楼分别建模；钟楼灰砖石、可穿透基座和上层钟体，鼓楼红台基、木构柱廊和不同檐层。二维屋脊形式也应对应，不能沿用同一个金色宫殿模板。
- **模型解释与待补**：楼梯、构件、绿剪边宽度、钟鼓器物和局部细部仍作导览概化；图书馆参考图编号106、109—113的逐图出处与再利用许可尚需完整登记。自制模型对照见图册。
- **实现位置**：`src/scene/northernLandmarks.ts`、`src/components/FlatMap.tsx`。

## 03 · 景山 `jingshan`

- **文化依据**：`GEN-BEIJING`、`GEN-PLAN`支持景山与宫城、城市轴向和北海的关系，`GEO-BEIHAI`补充相邻园林背景。

- **设计取舍**：表达东西展开的山脊与五个亭位，保留面向故宫的俯瞰关系；避免以一个半球替代整个山体。
- **模型解释与待补**：山势为程序化解释，非DEM实测地形。早期亭子高度与屋顶缺乏专门依据的状态由下列2026-11-14五亭记录补正；逐亭立面、现状照片与节点尺寸仍待补，不称精确复原。
- **2026-11-14越界修正**：先前程序山脊按固定宽度延展，未按公园/道路裁限，导致西侧与南侧坡脚压到路面；该表达由本次约束取代。沿用 `GEO-OVERPASS` / `GEO-OSM` 的既有公园way `29201967`与周边道路，核对公开公园外环与原始归档逐点相符。公园范围用于最大允许边界，不能称为实际山脚等高线。
- **建模参数**：在园界内退6m，避开既有道路显示范围及其外侧4m余量，剩余约束距离20m内用平滑函数让坡面落地；这些距离与道路宽度均是显示解释，非测绘。剔除跨越边界的山体/步道三角形，五亭与树根共用受约束高度场，树木额外考虑树冠半径，避免只收树干而树冠仍占道路。保留五峰亭位，未移动道路以迁就地形。
- **本轮范围与限制**：仅修复地形/树木越界；无DEM、山脚现状测量或逐树调查，未把五峰程序山势升级为精确地貌复原。本轮实际验证及截图见[校核图册](figures/README.md)。
- **2026-11-14树木穿建筑修正**：用户截图显示树木侵入配房。原植树只按OSM建筑外接框加固定余量排除树干，漏掉程序补出的两侧配房与前殿；五亭显示台基也大于部分地图轮廓。现在 `src/scene/jingshanLayout.ts` 共享补充建筑布局，按屋檐、前阶及亭台的模型包络加完整树冠安全半径筛选树位。沿用 `GEO-OVERPASS` / `GEO-OSM` 本地数据，未新增现实建筑、移动建筑或修改地理快照。包络外0.15场景单位及树冠半径×1.9+0.12均是防穿插参数，不是现状测量；逐树清单和配房形制依据仍待补。回归测试 `src/scene/jingshanTrees.test.ts` 直接检查生成建筑网格，覆盖有/无建筑快照的情况。
- **2026-11-14五亭形制与细部修正**：新增 `JING-WANCHUN-PARK`、`JING-JIFANG-PARK`、`JING-ZHOUSHANG-PARK` 三条管理机构建筑说明及 `JING-DPM-P38` 故宫托管研究单页（印刷页38），均本日直接下载核对。万春亭改为三重檐四角攒尖、32根红柱；辑芳/观妙为双檐八角绿瓦黄剪边，富览/周赏为双檐圆顶蓝瓦紫晶色剪边。五亭高度按管理机构文字分别取17.4、12.05、11.75米，平面木构尺度参考PDF的17.01米正方形、10.41米八角直径、7.87米圆亭直径。地图仍只用于五亭中心定位；不再把较小的地图内环当作完整建筑高宽。
- **细节表达与限制**：`src/scene/jingshanPavilions.ts` 以弧面、裙檐中孔、卷瓦条和角脊替代双层实心锥体，补出内外柱列、青绿梁枋、简化斗拱、内圈槛窗与南北通口、石台和台阶。PDF支持青绿点金旋子彩画的类别，但模型的金色菱形和叠块不是纹样或斗拱出跳的精确复刻。内外柱分配、门窗开口、檐口高度、出挑、台阶尺寸、瓦纹密度均为模型解释；没有造出未考证的佛像。官方夜景远图只作总体观察，未复制为运行素材。PDF全文作者、题名和图版仍待补。
- **共享约束**：五亭包络供 `jingshanLayout.ts` 的完整树冠避让使用；峰顶平整半径覆盖新石台，避免台基悬空，同时继续遵守已有园界与道路高度衰减。未改变投影、地图快照、亭位与分区接口。验证与本轮模型截图见[五亭校核](figures/README.md#2026-11-14--景山五亭细化)。
- **实现位置**：`src/scene/layouts.ts`、`src/scene/jingshanTerrain.ts`、`src/scene/architecture.ts`、`src/scene/forest.ts`；回归检查 `src/scene/jingshanTerrain.test.ts`。

### 2026-11-14 · 故宫西北部院墙遗漏

- **问题与根因**：用户截图中的西北部多处院落连成空地。原 `building` 查询只包含封闭建筑/墙体面，未下载 `barrier=wall` 开放线；已有 `院墙` 面没有涵盖全部围墙。因此不是把空地重新划分成猜测的矩形，而是补入遗漏的数据类别。
- **地图证据**：沿用 `GEO-OVERPASS` / `GEO-OSM`。2026-11-14实际下载历史时点对齐原建筑的专门查询，取得189条开放围墙way和3个入口节点；原始数据、查询文本、坐标系与哈希见 `data-manifest.json`。西北部例子包括 `42311507` / `42311508` 与 `42348519` / `42348520` 等墙段。全部原始线为WGS84，经既有GCJ-02转换和同一投影，不用POI反推围墙。
- **实现与取舍**：`src/scene/palaceWalls.ts` 按源折线生成红墙、石脚和灰色小坡顶，按宫城外环裁切；与既有建筑、院墙、廊庑的实际多边形及边缘余量排除重叠，避免贯穿或重复墙。保留源入口及建筑门洞，两维/三维共享 `palaceWallRuns`，不自动连接源数据断口或首尾补边。
- **模型参数与限制**：默认内墙高3.8m、厚0.65m、墙顶宽1.2m，入口无宽度标签时留约1.4m，建筑边缘另退0.6m以容纳墙帽。这些是显示参数，非测绘；既有外墙沿用10m表达，不按4条OSM city_wall的4m标签改写宫墙史实。灰顶配色及细部不称逐段考证。地图仍可能缺墙，未完成全部宫院的现状测绘核验。
- **验证**：`src/scene/palaceWalls.test.ts` 检查西北墙段恢复、源线来源、宫界约束、凹形建筑裁切、去重和入口；与既有院墙细节及 `wallRuns` 回归一起验证。实际结果和同视角截图见[图册](figures/README.md#2026-11-14--故宫西北部围墙补全)。
