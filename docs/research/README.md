## 证据的使用边界

文化事实优先使用遗产机构、文物主管部门和博物馆文字；地图支持位置和轮廓；照片支持可见形态；用户反馈支持软件问题和表达要求。模型截图、编译和测试只能说明实现，不能倒推历史事实。

WGS84 快照、GCJ-02 锚点、显示投影和导航调整分别记录。估算高度、插值院墙、树位、程序纹饰和补建细节均为模型解释，不标为实测或完整复原。来源冲突继续保留，例如万宁桥镇水兽数量与永定门历史/复建尺寸分别记载。

## 尚待补齐

- 部分原网页只留下会话摘记或临时缓存，长期原文归档、PDF 正式书目信息与精确页码仍不完整。
- 部分照片缺逐图作者、原始文件页或可分发许可；未确认授权的外部照片不作为运行纹理或交付素材。
- 景山五亭、各城门逐檐标高与构造、故宫细部和逐段内墙、天坛路缘及院内分隔仍缺测绘依据。
- 新增 POI 与未成功的 Overpass 查询不等于取得新地理快照；查询失败原文和原坐标继续保留。
- 本轮没有执行自动化测试套件；北段 PR 接入后的手动浏览器检查范围见[进度记录](../progress.md)。本轮没有生成模型校核图，现有图册不能替代当前软件页面检查。
