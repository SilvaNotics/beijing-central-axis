# 故宫内墙排布与内务府续修 · 2026-11-14

用户要求以提供的故宫示意图修正内部墙壁，并通过多张项目模型截图指出越界、断接、穿插、内务府屋顶及南侧整排房屋的问题。重发参考图已通过WSL路径读取，忽略目录保留本地工作副本；原作者、题名、年代、网址及许可待核，不公开再分发或作为运行纹理。登记为 `USR-PALACE-WALL-PLAN-20261114`；圈注、北接箭头及整排反馈另登记 `USR-PALACE-WALL-FEEDBACK-20261114`。

## 依据和修正范围

- **地图几何**：沿用 `GEO-OVERPASS` / `GEO-OSM` 的既有墙线、入口、建筑轮廓。本轮未联网刷新或修改WGS84快照。地图建筑外包络并不等于檐下木构立面。
- **图示观察**：用户示意图支持院落横纵关系和局部矩形围合；模型截图确定需要调整的对象及北接方向。两者均不提供实测尺寸，不据此新增历史文字结论。
- **模型解释**：墙体高度、厚度、屋面细节、接楼偏移和三组新增院界仍是概览参数，不是历史复原或逐段现状认证。

## 取代的试作

旧端点近邻配对及孤立网络自动闭合混淆了建筑裁切端、现有交点和独立构件，曾将way/43519305两端连到其他院墙，额外长度约31.79米、54.60米。两套逻辑已撤销。用户明确独立构件有功能后，保留其原短段，未执行接长或删除提议。此前“内部房屋与短墙断口”记录中的自动闭合结论由本项取代，历史记录不删除。

初轮对整座故宫扩大建筑裁切边界的试验造成其他接缝，已撤回；现仅对明确对象调整墙线，沿实际轮廓裁切。

## 最终建模决定

1. **三组具名院界**：武英殿侧院、西南服务院及御茶膳房西侧院通过明确路径连接既有节点，带源way ID、`layoutRepair`和解释标记；按宫界、建筑和已知入口裁切。西侧显示开口是导航选择，不能当作测绘门址。撤去缺少依据的大范围北侧矩形和厨房东侧闭合试画。
2. **内务府北接**：way/42569643撤去楼下短尾，绕40542466屋面东侧，接入41657480既有节点。0.35单位避让距离是显示参数。上方41657480自身路径未重排。
3. **南侧整排房屋**：42569643横段使用40542464/65的纵向中心建立接楼线，进入建筑轮廓后裁切；西端在650787466与40542462之间的空隙转折。旧横线沿檐边掠过，露在多栋房屋立面前；本轮移至房屋接口之间。42569638局部直角化，42569633共用节点同步。
4. **东侧端头**：42681371、653251437、654664219、1341826248以649255320、40544224、40544226、40544225为对应接口，墙端不再沿整座长屋外缘延伸。共用T节点同步；进入轮廓的线仅供裁切计算，不绘制穿过房间的实体墙。
5. **檐下连接**：只允许沿父墙方向或垂线，检查归属建筑、其他建筑及入口。沿整条返墙在0.12、0.23、0.40单位高度采样，遇最早实体即停止；终点两侧0.0001单位偏移下须稳定接触，极短向量不用于射线方向。共享工程同期东侧穿插修正把四栋房屋接头限定到外柱，并将墙帽按自身截面独立裁短，避免后退整段墙身造成断口。15米总路程、4米横返及采样位置是模型参数。缓存墙身高度网格并按包络预筛相邻建筑，减少重复查询。有限射线采样不等同完整实体布尔验证。
6. **内务府屋顶**：保持既有凹形网格和开敞空间，从原折线、坡面生成屋脊、檐边及顺坡瓦垄；只在40542466接入，不重新叠加矩形屋顶。脊形、节距、檐高和完整现状形制仍待专门资料。
