# 北段纸雕章节的资料与建模说明

记录日期：2026-11-14。该章节来自 GitHub PR #1，合并提交 `f1d9cf7828629391c49dedb7b7419dcc0334724f`。本记录只说明接入后如何理解已有页面与证据边界；没有在线重查作者所引资料，也不把页面作者的自检结果当成本轮结果。

## 已有来源的使用范围

章节地名介绍卡和逐句小注是页面内容，其列出的文物、政府、管理机构出版物对应主项目已经登记的来源记录。钟鼓楼建筑事实可对照 `TOWER-HERITAGE`、`TOWER-CITY`；万宁桥事实可对照 `BRIDGE-HERITAGE`、`BRIDGE-CITY`；景山五亭和公园背景可对照 `JING-WANCHUN-PARK`、`JING-JIFANG-PARK`、`JING-ZHOUSHANG-PARK`、`JING-DPM-P38`、`JING-ROUTES`。这些来源的出版字段、核验日期、冲突、原件存档和图像许可限制仍以[结构化来源登记](source-register.json)及[逐地标证据矩阵](evidence-matrix.md)为准。本轮没有补证、没有修改来源核验状态，也没有增加重复来源 ID。

具体台词中的炉温、铸造过程、船工逐闸等候、役夫挑土等第一人称细节，不是由上述简要网页条目逐项证明的历史记录。页面中的人物是创作角色，叙事把不同年代的城市变化交织在永乐年间的戏剧场景里；不得作为同时代口述或史料引用。小注提示其查证方向，但需要原书、版本和页码才能逐条审定。

## 画面与接入

- [北段 HTML](../../public/chapters/north/index.html)：单页原生网页；地图、卡片、人物和背景是作者制作的纸雕导览画面。
- [素材说明](../../public/chapters/north/docs/sources.md)：作者报告地图、人物、纸纹与动画为 AI 生成后编辑；字体子集及音乐、音效有各自的来源与许可说明。项目未重新审查每项素材的原始生成记录或二次使用条件。
- 地图图片不是正射影像、测绘成果、WGS84/GCJ-02 数据或比例地图。页面热点位置是叙事和导航安排，不作为精确地理坐标。
- 章节沿用 `north` 和 `chapters/north/index.html` 固定入口。原生静态 HTML 及相对资源不要求改主项目章节数据。
- 独立返回采用 `../../#/`；嵌入时隐藏章节自己的返回链接，只显示父应用返回按钮，避免重复。章节保留精确同源 `axis:return` 消息处理，父层继续校验发送窗口和 origin。
- 竖屏下纸雕图保留横向展示，介绍与人物入口改为可读按钮列表；地图上的文字热点不再被缩成小尺寸继续承担手机点击操作。

## 本轮实际验证和限制

本轮使用本地静态 HTTP 服务和单实例 Chromium 检查 1600×900、320、390 与 768 像素宽页面，查看了卡片、人物对话、窄屏溢出、键盘推进及焦点还原。另在生产预览中打开正式 `#/chapter/north` iframe，点按章节返回，观察父应用返回到 `#/`。页面控制台没有脚本错误，检查时没有 HTTP 失败；运行资源走本地路径。未运行 Vitest 或 Playwright 测试集。检查没有覆盖真实屏幕阅读器、真实触屏设备、多浏览器媒体解码差异和最终部署环境。

完整几何取舍和逐地标来源仍见[证据矩阵](evidence-matrix.md)；构建、提交和未执行事项见[进度记录](../progress.md)。
