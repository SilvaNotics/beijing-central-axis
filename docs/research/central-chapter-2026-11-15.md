# 中段正式互动章节 `public/chapters/central/`

## 接入与对应关系

2026-11-15 将用户提供的 Windows 桌面 `www` 静态页面整理为正式中段章节，实现提交为 `30c353a725490268f8814feea554778d2b2cee38`。沿用稳定章节 ID `central` 和入口 URL `chapters/central/index.html`。页面以五幅人物热点对应五项中段遗产：故宫 `forbidden-city`、社稷坛 `shejitan`、太庙 `taimiao`、端门 `duanmen`、外金水桥 `jinshui`；未修改主应用地标 ID、分区归属或 iframe 契约。

## 证据口径

- **文字事实**：本轮没有新增历史来源，也没有重新在线核验既有页面。宫城礼序与遗产背景沿用 `GEN-AXIS`、`GEN-BEIJING`、`GEN-PLAN`；故宫沿用 `GEN-PALACE`；端门尺寸与形制沿用 `DUAN-DPM`；外金水桥沿用 `JINSHUI-SWJ`、`JINSHUI-2019`。各来源的原始核验日期、页码和限制以[来源目录](source-catalogue.md)及[逐地标证据表](evidence-matrix.md)为准。
- **待复核叙述**：页面中端门的建置年代、明清热河仪仗用途、“端礼门”称谓，以及外金水桥重建年代和逐级通行规则，尚未逐句映射到现有来源结论；交付记录中明确列为待复核，不把整合行为写成新一轮史料核验。
- **地图与热点**：背景图是用户提供的画卷式导览插画。五个人物位置服务于视觉叙事和点击，不是GIS坐标、建筑轮廓、遗产边界或考古定位；地图中轴线与建筑关系也不能反过来当作比例测绘。
- **创作角色与影像**：五位介绍者是现代导览角色，不是历史人物肖像或证言。建筑画卷、人物图和视频的逐项作者、制作方式、来源与授权未随目录提供，均待补；详见章节[来源与素材说明](../../public/chapters/central/docs/sources.md)。
- **来源冲突**：`JINSHUI-SWJ` 与 `JINSHUI-2019` 对两侧公生桥孔数的表述不一致。章节只支持七座桥及其总体对应关系，没有补造逐桥孔数细节。

## 实现与界面

章节为独立原生 HTML，内部资源均使用相对路径并随 `public/chapters/central/` 完整部署。原有画卷开合、影像与文字切换、本次探访进度、人物位置微调均保留；接入层补充了唯一 `h1`、动态状态播报、地图替代文本、微调按钮状态、精确同源 `axis:return` 消息，以及独立打开时的返回总览链接。

页面在 iframe 中隐藏章节自身返回链接，避免与父应用控制重复；独立模式仍保留链接。全部样式、图片、视频与脚本本地加载，不依赖远程字体、CDN 或地图瓦片。
