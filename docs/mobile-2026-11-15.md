# 2026-11-15 · 手机地图交互修复

环境：WSL Bash、Node.js 24.20.0、生产构建、Playwright Chromium 触摸模拟。版本与最终检查输出见 [进度记录](progress.md)。本轮不改变地标内容、地理数据、人物创作或章节入口契约。

## 原因与交互取舍

- 主地图的单指手势原来固定为平移，双指为缩放与平移，旋转只能通过桌面 Shift 拖动进入。在 [主界面](../src/App.tsx) 加入带 `aria-pressed` 的「旋转」按钮；开启后单指拖动旋转，再按一次恢复平移。双指仍负责缩放与平移；全轴总览和切换二维图恢复默认平移。桌面 Shift 旋转、Ctrl 平移继续保留。手势由 [场景控制](../src/scene/SceneView.tsx) 在每次 pointerdown 时配置，拖动与多指动作不按地标点击处理。
- [二维图](../src/components/FlatMap.tsx) 原来仅有 wheel 缩放，pointer 只追踪一个 ID。现在追踪触点，双指间距控制缩放，两指中点作为地图锚点。坐标通过 SVG 的屏幕转换矩阵换算，包含等比显示的留白。松开一指后从剩余触点继续平移；cancel 或 capture 丢失时清理触点。捏合和拖动后阻止误触地标，正常轻点与键盘选择保留。缩放范围沿用 0.85–12。
- [北段章节](../public/chapters/north/index.html) 的 `max-width:900px` 样式原来直接隐藏 `.marker`，头像资源本身没有缺失。恢复三个人物圆牌，继续使用原地图百分比锚点，采用 44–64px 图像和至少 44px 触控区域；移动导览的文本入口继续可用。地名、对话文本与素材未改。
- [窄屏工具栏](../src/styles.css) 为各按钮提供至少 44×44px 操作区，触摸设备显示单指/双指提示。手机底部将操作栏、手势说明与图例分开，避免覆盖；简短说明仍位于页面其他位置。

## 回归用例与边界

[移动端用例](../e2e/mobile.spec.ts) 覆盖三维平移/旋转切换与罗盘、总览重置、二维双指放大缩小和锚点保持、双指转单指、正常地标轻点、320/390/768px 操作区及溢出检查、北段三张头像实际解码、对话打开和返回焦点、Enter/Escape。桌面 [既有用例](../e2e/atlas.spec.ts) 保留鼠标手势、地标、二维滚轮和 iframe 返回检查；返回断言按当前契约改为使用父应用按钮，iframe 内重复返回链接隐藏。

修改前已在浏览器复现缺失旋转入口、二维捏合比例保持 1、头像 `display:none`。开发过程中修正了测试的触点结束语义与拖动后被地标标签覆盖的起点，保留实际症状的断言。

Chromium 的 CDP 注入拖动会吞掉紧接着的第一次模拟触摸点击；已在只有普通 div 和 button 的空白页面复现。三维回归在注入手势之间使用按钮标准 click 路径，手势本身仍通过真实浏览器触摸事件发送。软件 WebGL 首帧和每帧开销较大，先等待罗盘首次更新，再比较旋转和复位；没有放宽角度或缩放断言。以上检查不代表真实 iOS Safari、Android 设备、读屏和全部媒体解码已验收。

## 对话说明遮挡人物的补修

用户截图显示，北段对话的创作说明压住了役夫的头部。原因是窄屏说明固定在顶部 76px，而人物按视口高度的百分比独立定位；嵌入父应用后可用高度缩短，两者就会重叠。窄屏对话现用网格先为说明保留实际高度，再从下方排列人物，间隔 12px；说明换行后会自动让出空间。顶部保留章节工具操作区，底部仍保留对话纸带。没有改动说明文案、人物素材或桌面样式。

生产构建后运行 `npx playwright test e2e/mobile.spec.ts --grep 'north' --workers=1 --reporter=line`，2 项通过（10.6 秒）。独立页面在 320/390/768px 宽逐一打开三个人物；父应用 iframe 在 320×844、390×844、390×667、768×1024 逐一检查，断言说明与已解码立绘之间至少保留 8px、立绘高度超过 100px、对话可读并可返回原入口焦点，无横向溢出或页面异常。已目视检查四种嵌入尺寸的役夫截图；截图与断言仅代表 Chromium 触摸模拟，未补做真机验收。本次为样式修正，未重跑主图手势或单元测试；先前整套结果对应前述版本。
